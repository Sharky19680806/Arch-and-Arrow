# Booking engine — design canvas

Client-facing wedding enquiry and 7-day date-hold flow for Arch and Arrow.

- `Main.dc.html` — desktop enquiry flow (clickable: date → package → details → hold)
- `Mobile.dc.html` — mobile date step
- `Held.dc.html` — "date held" confirmation
- `canvas.json` — canvas layout and notes
- `arch-and-arrow-booking-engine.html` — the seeded canvas (open in a browser to view/export)

All rand figures are sample values. Real facts are bracketed, e.g. `[VENUE PHONE]`.
